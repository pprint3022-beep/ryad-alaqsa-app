# Ryad Al Aqsa Backend (تنفيذ فعلي للبنية)

خادم Node.js (بدون تبعيات خارجية) يطبّق: فصل البوابات، مصادقة برموز (JWT-like HMAC)، RBAC مع نطاق، سجل تدقيق، وتقارير مرتبطة ببيانات حقيقية (حضور/واجبات/درجات) وإدارة مناهج.

## التشغيل
```bash
cd ryad-alaqsa-app/backend
node server.js
```
- الخادم: `http://localhost:3001`
- يقدم الواجهة الأمامية أيضًا من مجلد التطبيق (`/` -> `index.html`) وواجهات API تحت `/api/*`
- التخزين: ملف `data.json` (بيانات تجريبية + سجل تدقيق يُحدّث).

## الفصل الفعلي بين البوابات
- `POST /api/auth/login` يتطلب `portal` = `admin_portal` أو `private`.
- التوكن يحمل `portal` و`role` و`scope`. أي طلب لـ `/api/admin/*` من بوابة خاصة يُرفض (403)، والعكس.
- الحسابات الخاصة (معلم/ولي/تلميذ) لا يمكنها الولوج عبر بوابة الإدارة.

## RBAC والنطاق (أمثلة مطبقة)
- **معلم:** وصول تقارير التلميذ فقط إذا كان ضمن فصوله (`scope.classes`).
- **ولي أمر:** وصول تقارير أبنائه فقط (`scope.children`) — حماية خصوصية.
- **تلميذ:** وصول ملفه ومناهج مستواه فقط.
- **إدارة المحتوى:** إنشاء/قراءة المناهج (`/api/admin/curriculum`) مقيد بأدوار إدارية محددة (مدير/نائب/إدارة).
- **سجل التدقيق:** تسجيل الدخول وقراءات/إنشاءات حساسة في `auditLogs`.
- إجراءات مطبقة إضافيًا: اعتماد/تحديث بطاقات التغذية الراجعة، تحديث الحالات، وإضافة أحداث الخط الزمني تُسجَّل مع تفاصيل في `auditLogs`.

## أولويات مطبقة (تضمين وتطوير)
- **بطاقات التغذية الراجعة (دورة حياة):** حالات مقترحة/معتمدة/مرفوضة/قيد التنفيذ/منجزة، إسناد وملاحظات وتاريخ تغييرات وتدقيق.
  - `GET/POST /api/admin/feedback-cards`, `POST /api/admin/feedback-cards/update`
  - مرادفات المعلم (ضمن النطاق): `GET/POST /api/teacher/feedback-cards*`
- **إدارة الحالات والتتبع الزمني:** تحديث حالة/مالك/تركيز/موعد مراجعة وإضافة أحداث للخط الزمني عبر الفصول.
  - `GET /api/admin/cases`, `POST /api/admin/cases/update`, `POST /api/admin/cases/timeline`
  - مرادفات المعلم (ضمن النطاق): `GET/POST /api/teacher/cases*`
- **نموذج كفايات مرجعي موحد:** `competencyReferences` وربطه بالتحليلات.
  - `GET /api/admin/competency-refs?level=` و `GET /api/teacher/competency-refs?level=`
- **ربط الواجهة بالخلفية:** تسجيل دخول API وحفظ token وعرض حي للمساعد الاجتماعي/بيئة الوكلاء مع إجراءات واعتماد وتراجع تجريبي عند غياب الخادم.

## ربط التقارير بالبيانات الحقيقية
- `GET /api/teacher/student-report?studentId=...` (معلم، نطاق فصوله)
- `GET /api/parent/child-report?studentId=...` (ولي، أبناؤه فقط)
- `GET /api/student/profile` (تلميذ)
التقرير يُبنى من: الحضور (`attendance`)، الواجبات والتسليمات (`assignments`,`submissions`)، الدرجات (`grades`) مع إرشادات دعم.

## إدارة المناهج والمحتوى التعليمي
- المواد مصنفة: لغات أساسية (عربية/فرنسية/إنجليزية/أمازيغية)، لغات اختيارية (إسبانية/ألمانية/إيطالية)، ومواد أخرى (رياضيات، تربية إسلامية، نشاط علمي، ثقافة، تاريخ وجغرافيا).
- المناهج مرتبطة بالمستوى والمادة والوحدات/الدروس وحالة النشر (`/api/admin/curriculum`, `/api/student/curriculum`).

## ملاحظات إنتاجية
- استبدال `data.json` بقاعدة بيانات (PostgreSQL)، تشفير كلمات المرور (bcrypt)، أسرار/مفاتيح قوية، HTTPS، تجديد رموز، وتوسيع RBAC وسجل التدقيق حسب `docs/`.
