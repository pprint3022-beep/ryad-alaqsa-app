# نظام متكامل للتعلم، التقييم، واكتشاف المواهب وسد الفجوات
**المؤسسة:** Institut Ryad Al Aqsa / رياض الأقصى (تمهيدي – السادس ابتدائي)  
**الهدف:** استثمار بيانات كل تلميذ لتحسين التعلم، اكتشاف المواهب وتنميتها، واكتشاف المتعثرين/الفجوات ومعالجتها مبكرًا.

---

## 1) المبادئ الأساسية
- **كل تلميذ له مسار:** دعم، مسار عادي، أو إثراء (قابل للتغيير حسب الأدلة).
- **مبكرًا أفضل:** اكتشاف الفجوة قبل تراكمها، واكتشاف الموهبة قبل إهمالها.
- **حلقة مستمرة:** تقييم ← تغذية راجعة ← بناء مسار ← تنفيذ (تمارين/أنشطة) ← إعادة تقييم.
- **الإنسان في المركز:** التوصيات والتحليلات **مساندة**؛ الاعتماد والتدخل النهائي بمراجعة المعلم/المشرف/الإدارة وبمشاركة الأسرة.
- **خصوصية وعدالة:** وصول للبيانات حسب الدور والنطاق، واستخدام مسؤول للذكاء الاصطناعي والتحليلات.

## 2) حلقة التقييم والتعلم (الدورة التشغيلية)

| المرحلة | الهدف | المدخلات (بيانات) | المخرجات | المسؤولون |
|---|---|---|---|---|
| **1. التقييم** | قياس التعلم والكفايات والسلوك التعلمي | درجات، واجبات، حضور، ملاحظة صفية، تقييمات مهارية/أدائية | مستوى إتقان (mastery)، مؤشرات أداء | معلم (+ مشرف) |
| **2. التغذية الراجعة** | توضيح نقاط القوة وما يجب تحسينه | نتائج التقييم، أخطاء شائعة، تقدم زمني | ملاحظات للتلميذ، تقرير للأهل، توصيات | معلم |
| **3. التصنيف والتشخيص** | تحديد الحالة والمسار المناسب | كفايات، اتجاهات، سلوك/انخراط، اهتمام/موهبة | تصنيف: فجوة/دعم، عادي، موهوب/واعد + أولويات | معلم + مشرف + إدارة تربوية |
| **4. بناء المسار التعلمي** | خطة مخصصة وقابلة للتنفيذ | التشخيص، أهداف مستوى، وقت متاح | مسار (أهداف، خطوات، تمارين، أنشطة موازية، موعد إعادة تقييم) | معلم (بإشراف) |
| **5. التنفيذ والتحفيز** | تعلّم نشط واستمرارية | تمارين، موارد، أنشطة، دعم منزلي | إنجازات، مشاركات، تقدم | تلميذ + معلم + أسرة |
| **6. المراقبة والتنبيه** | متابعة مستمرة واكتشاف مبكر | حضور، تسليم، درجات، تفاعل، ملاحظات | تنبيهات (تعثر/غياب/تراجع أو تميز) وتوصيات محدثة | النظام + معلم/مشرف |
| **7. إعادة التقييم** | قياس أثر الخطة وتعديلها | نفس مؤشرات التقييم بعد فترة | استمرار/تعديل/إنهاء برنامج دعم أو إثراء | معلم + مشرف |

> **وتيرة مقترحة:** تغذية راجعة مستمرة؛ مراجعة مسار كل 2–4 أسابيع أو حسب الحاجة؛ تنبيهات فورية/أسبوعية للمخاطر.

## 3) التصنيف والبرامج المستهدفة

| الفئة | مؤشرات (أمثلة) | الإجراء/البرنامج | المتابعة |
|---|---|---|---|
| **فجوات/صعوبات تعلم** | إتقان منخفض (<50%)، تراجع درجات، واجبات غير مكتملة، أخطاء متكررة | **برنامج دعم:** تمارين تدريجية تكييفية، مجموعات صغيرة، دعم فردي، تنسيق مع الأسرة | تنبيه مبكر + إعادة تقييم قصيرة (2–4 أسابيع) |
| **في المسار (عادي)** | إتقان متوسط/جيد وتقدم مستقر | مسار عادي + أنشطة موازية استكشافية | متابعة دورية وتحفيز |
| **واعد/موهوب** | إتقان عالٍ، سرعة فهم، حل مشكلات، اهتمام عميق، إنجاز متميز | **برنامج إثراء إبداعي:** تحديات متقدمة، مشاريع، مسابقات، أنشطة نوعية | توسيع المسار دون إهمال التوازن والجانب الاجتماعي |
| **حالة مركبة** | موهبة في مجال مع فجوة في آخر | مسار مزدوج: دعم موجه للفجوة + إثراء لنقطة القوة | تنسيق دقيق ومتابعة شاملة |

## 4) مجالات الأنشطة والمواهب (اكتشاف وتنمية)

### 4.1 الآداب واللغات
- **اللغة والكتابة الإبداعية:** شعر، قصيدة، قصة قصيرة، تعبير وسرد.
- **اللغات:** تعزيز الأساسية (عربية، فرنسية، إنجليزية، أمازيغية) واكتشاف ميول للغات اختيارية (إسبانية، ألمانية، إيطالية) عبر نوادٍ/أنشطة.

### 4.2 العلوم والتكنولوجيا
- **النشاط العلمي:** تجارب، استكشاف، مشاريع مبسطة.
- **تكنولوجيا:** نادي **Arduino** والروبوتيك، برمجة/تفكير حسابي مبكر.
- **رياضيات متقدمة:** تحديات، أولمبياد/مسابقات رياضيات (تحضيري محلي/وطني/دولي حسب المستوى).

### 4.3 الفنون والثقافة
- **فنون أدائية:** مسرح، موسيقى، إنشاد.
- **ثقافة:** ثقافة عامة وخاصة، مشاريع معرفية وعروض.

### 4.4 الرياضة والألعاب الذهنية
- **رياضة:** كرة القدم وأنشطة بدنية جماعية (انضباط، تعاون، صحة).
- **ذهنية:** شطرنج (تفكير استراتيجي، تركيز، تخطيط).

### 4.5 أنشطة إشعاعية مجتمعية ونشر
- **نوادٍ دورية ومسابقات ومعارض:** مشاركة داخلية وخارجية (محلية/وطنية/عالمية تحضيرية حسب المجال).
- **نشر واستثمار:** عرض الإنتاجات (كتابية، فنية، علمية، لغوية، رياضية/ذهنية) للأسر والمجتمع، وتوثيق الأثر.
- **الهدف:** إشعاع المؤسسة، تعزيز الدافعية، وربط التعلم بالحياة والمجتمع.

> **مبدأ:** إتاحة أنشطة استكشافية للجميع + مسارات نوعية للمهتمين/المتميزين، مع ربطها بمؤشرات الموهبة والتقدم واستثمارها إشعاعيًا.

## 5) الاستفادة من بيانات التلاميذ (التحليل والتوصية)
**مصادر البيانات:** حضور، درجات وتقييمات، تسليمات وملاحظات، كفايات (إتقان مهارات)، مشاركة في أنشطة، ملاحظات معلم/مشرف.

**مخرجات ذكية/تحليلية (مساندة):**
- **تحليل اتجاهات:** تحسن/تراجع عبر الزمن لكل تلميذ/فصل/مستوى.
- **اكتشاف مبكر:** تنبيهات فجوات، غياب متكرر، تراجع مفاجئ، أو مؤشرات تميز.
- **تغذية راجعة مخصصة:** نقاط قوة + أولويات تحسين بصيغة واضحة للتلميذ والأسرة.
- **اقتراح تمارين:** تكييفية حسب الفجوة/المستوى (دعم أو إثراء).
- **اقتراح أنشطة موازية:** بناءً على الاهتمام والأداء (مثلاً ميل علمي → روبوتيك/مسابقات رياضيات).
- **توصيات متابعة:** وتيرة إعادة التقييم، تواصل مع الأسرة، إحالة لمشرف/برنامج دعم.
- **لوحات للمعلم والإدارة:** تصنيف الفصول، تتبع البرامج، قياس أثر التدخلات.

**ضوابط:** مراجعة بشرية للتوصيات المؤثرة، شفافية مبسطة للأسر، حماية خصوصية البيانات، وتجنب وصم التلاميذ (التصنيف أداة دعم لا حكم ثابت).

## 6) أدوار المنظومة (من يفعل ماذا)
- **التلميذ:** الالتزام بالمسار، إنجاز التمارين/الأنشطة، طلب المساعدة، المشاركة.
- **المعلم/ة:** التقييم والتغذية الراجعة، بناء/تحديث المسار، اقتراح أنشطة، رصد تقدم، تواصل مع الأسرة.
- **ولي الأمر:** متابعة التقارير، تطبيق توصيات الدعم المنزلي، التواصل والتشجيع.
- **المشرف:** متابعة الانضباط والحالات الحرجة/المتميزة، دعم المعلمين، ضمان الاتساق.
- **الإدارة:** توفير الموارد والبرامج والأنشطة، متابعة الأداء والمؤشرات، تنسيق الشراكات.
- **المدير:** اعتماد السياسات والأولويات، تخصيص الموارد، متابعة الأثر الاستراتيجي.
- **النظام (منصة):** جمع البيانات، حساب المؤشرات، توليد تنبيهات وتوصيات مساندة، تتبع المسارات وإعادة التقييم.

## 7) مؤشرات نجاح النظام
- **سد الفجوات:** نسبة تلاميذ انتقلوا من "فجوة" إلى "في المسار" بعد تدخل.
- **تنمية المواهب:** عدد الموهوبين/الواعدين المكتشفين والمشاركين في مسارات إثرائية وإنجازاتهم.
- **استمرارية:** تحسن الحضور والانتظام وإنجاز الواجبات.
- **دقة التدخل:** زمن اكتشاف الحالة، الالتزام بإعادة التقييم، فعالية البرامج.
- **رضا وشراكة:** تفاعل الأسر والمعلمين وجودة التواصل.
- **أثر بيئي:** ربط المدرسة بالأنشطة والشراكات والمسابقات وتطوير بيئة تعلم محفزة.

## 8) خارطة تنفيذ عملية
1. **توحيد أدوات التقييم والكفايات** لكل مستوى ومادة.
2. **تفعيل جمع البيانات المنتظم** (حضور، واجبات، درجات، ملاحظات، أنشطة).
3. **تكوين لوحات وتنبيهات** (فجوات/تميز/غياب) للمعلم والمشرف والإدارة.
4. **إطلاق برامج دعم وإثراء** بمسارات واضحة ومواعيد إعادة تقييم.
5. **تنظيم كتالوج الأنشطة الموازية** (آداب، علوم/تكنولوجيا، فنون، رياضة) وإتاحة المشاركة.
6. **إشراك الأسر** بتقارير وتوصيات عملية.
7. **مراجعة دورية للأثر** وتطوير المحتوى والبيئة باستمرار.
