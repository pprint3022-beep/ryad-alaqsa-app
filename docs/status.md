## 4) قرارات معمارية مثبّتة

1. **فصل البوابات:** `admin_portal` ≠ `private` على مستوى الوسيط والمسار.
2. **RBAC + Scope:** المعلم بفصوله، الولي بأبنائه، التلميذ بنفسه، الإدارة بنطاق المؤسسة.
3. **قرار بشري:** كل مخرجات AI استشارية، مع أدلة (`evidence`) وموافقة (`approval`) وسجل تدقيق.
4. **الخصوصية:** k-anonymity ≥ 3 في التحليلات، وتقليل البيانات في كل تقرير.
5. **التخزين:** JSON للنموذج، PostgreSQL + Prisma للإنتاج، Redis اختياري مع Fallback.
6. **اللغات:** ar (RTL) · fr · en · amz (Tifinagh)، مع إمكانية ES/DE/IT لاحقًا.
7. **الاحتفاظ:** سياسة قابلة للتطبيق + تدقيق، دون حذف ما يلزم قانونًا.

## 6) القيود الحالية

- لا يوجد `psql` أو `python` أو `pnpm` محليًا في بيئة التطوير؛ التحقق يتم عبر npm/workspaces (مطابق لـ CI).
  - PostgreSQL غير متاح محليًا؛ الـ seed جاهز ويُترجم TypeScript بنجاح لكنه غير مُنفّذ.
  - اختبارات ML (23 حالة في `services/ml`) جاهزة لكن لم تُشغَّل لغياب Python.
- توليد الصور غير متاح؛ الشعار أُعيد رسمه SVG مطابقًا للشعار المرفق.
- كتالوج الترجمات للأربع لغات مُوسَّع ليغطي مفاتيح صفحات الأدوار (1696 مفتاحًا لكل لغة) مع الحفاظ على RTL/LTR؛ قيم amz بالفرنسية بانتظار مراجعة أصلية.
- تعيينات تجارب ML محفوظة في الذاكرة فقط وتُفقد عند إعادة تشغيل الخادم (موضّح صراحةً في الواجهة).
- لا PostgreSQL محليًا ولا Python؛ migrations/seed واختبارات ML غير مُنفَّذة هنا. راجع `docs/review/2026-11-complete-review.md` للخارطة الكاملة.
