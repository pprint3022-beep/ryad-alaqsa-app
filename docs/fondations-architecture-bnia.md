# الأسس البِنْيَوِيّة للمنظومة (Ryad Al Aqsa) — تطوير الأفكار الجوهرية

> تاريخ التحديث: 2026-11-18  
> المرجعية: مؤسسة Institut Ryad Al Aqsa / رياض الأقصى (تمهيدي–السادس ابتدائي، سياق مغربي)  
> المبدأ الحاكم: **إنسان أولاً** (قرار ومراجعة بشرية)، خصوصية وإنصاف، أثر تربوي قابل للقياس.

## 1) الجذور (ثوابت لا تُمس)
- **العدالة والتنمية الشاملة:** دعم + مسار عادي + إثراء بدون وصم، وتنمية أكاديمية/مهارية/قيمية/اجتماعية/فنية/بدنية.
- **دورة التعلم الأساسية:** تقييم إدخال/تشخيص → تغذية راجعة → مسار تعلم → تنفيذ (تمارين/أنشطة) → إعادة تقييم → تحسين مستمر.
- **فصل الأدوار:** المساعد الاجتماعي/التربوي/النفسي = **متدخل إنساني مهني** يتابع الحالة عبر الفصول والسنة؛ بيئة الوكلاء = **أدوات مساندة** (استخلاص، تنبيه، مسودات، ربط أدلة) لا تستبدل القرار البشري.
- **الشراكة:** أسرة–مدرسة–مجتمع وأنشطة إشعاعية (نوادٍ، مسابقات، نشر) مرتبطة بالمسارات والأثر.

## 2) المعمارية المنطقية (طبقات)
1. **الهوية والوصول:** بوابتان منفصلتان (إدارة/خادم رئيسي، حسابات خاصة: معلم/ولي/تلميذ)، مصادقة، RBAC، نطاق (مستوى/فصل/أبناء/تلميذ)، وتدقيق.
2. **النواة التربوية (Domain):** تلاميذ/مستويات/فصول، كفايات مرجعية، تقييمات إدخال، حضور/واجبات/درجات، مواهب واهتمامات.
3. **محرك التوجيه:** تشخيص فجوات/قوة، تصنيف، مسارات تعلم، برامج تدخل (دعم/إثراء)، بطاقات تغذية راجعة بدورة حياة (مقترحة→معتمدة→قيد التنفيذ→منجزة/مرفوضة).
4. **متابعة الحالة:** ملف حالة زمني عبر الفصول/السنة، أحداث وتدخلات، استحقاقات إعادة تقييم، ربط سياقات ضمن الحدود المهنية.
5. **الأنشطة والأثر:** نوادٍ/مسابقات/معارض/منشورات إشعاعية، مؤشرات أثر (خط أساس/هدف/حالي) وتنبيهات استحقاق.
6. **التواصل المحكوم:** مسودات → اعتماد → إرسال مع موافقة/خصوصية وسجل.
7. **المعرفة والوكلاء:** مكتبة علمية/بيداغوجية، وكلاء متخصصون متعددون المستويات بمخرجات معيارية مرتبطة بأدلة.
8. **الحوكمة والمراقبة:** تدقيق شامل، سياسات احتفاظ/حذف/إخفاء هوية، قياس أثر، وإنصاف.

## 3) نموذج البيانات الأساسي (كيانات)
- **Identity & Access:** `users`, `roles`, `scopes`, `sessions/refresh_tokens`, `audit_logs`.
- **هيكل تعليمي:** `levels`, `classes`, `students`, `subjects`, `curriculum`.
- **الأداء والتقييم:** `attendance`, `assignments`, `submissions`, `grades`, `assessments` (إدخال/تشخيصي/تكويني)، `competency_references` (مهارة/مؤشر/عتبة لكل مستوى/مادة)، `student_competencies`.
- **التوجيه والتدخل:** `learning_paths`, `interventions`, `feedback_cards` (+history/actions)، `cases` (+timeline/events)، `alerts`, `talents`, `recommended_activities`.
- **الأنشطة والأثر:** `activities`, `publications`, `impact_log`.
- **المعرفة والوكلاء:** `library_resources`, `agent_profiles`, `agent_runs`, `evidence`, `drafts`, `communications` (+governance).
- **الإدارة والاستراتيجية:** `staff`, `finance`, `goals`, `strategy`, `partnerships`.

## 4) البنية الهرمية والربط الإحصائي
- **هرمي:** تلميذ ← فصل ← مستوى ← مؤسسة (تقارير وتجميع مع احترام النطاق).
- **زمني:** فصل دراسي/سنة، خط أساس → تدخل → إعادة تقييم → أثر.
- **سببي/أدلة:** كل توصية/بطاقة/تنبيه مرتبط(ة) بمصادر بيانات وأدلة (`evidence`) وسجل قرار بشري.

## 5) RBAC والنطاق (ملخص مؤسسي)
| الدور | البوابة | النطاق النموذجي | أمثلة صلاحيات |
|---|---|---|---|
| مدير/نائب/إدارة | إدارة | عالمي/مفوّض | قيادة، تقارير، اعتماد، استراتيجية، مالية (حسب الدور) |
| مشرف | إدارة | مستويات/فصول | إشراف تربوي، متابعة حالات، تنبيهات |
| كاتب | إدارة | عالمي تشغيلي | سجلات/وثائق/محتوى إداري |
| معلم | خاصة | فصوله | إدخال تقييم/حضور، تقارير ورؤى نطاقه، بطاقات/حالات ضمن النطاق، مسودات تواصل |
| ولي | خاصة | أبناؤه | تقارير ورؤى مبسطة، تواصل محكوم |
| تلميذ | خاصة | ذاته | مسار، تمارين، تغذية راجعة معتمدة |

## 6) الوكلاء المتخصصون (مساندة متعددة المستويات)
- **بيداغوجي/كفايات:** مواءمة تقييمات مع المرجع، اقتراح تمارين وتفريق تعليم.
- **اجتماعي-تربوي:** سياق، تنسيق تواصل أسري، متابعة خطة دعم.
- **مساندة نفسية-تربوية (مؤشرات):** إشارات رفاه/مشاركة ضمن الحدود المهنية وتحويل عند الحاجة.
- **مواهب وإثراء:** اكتشاف فرص وربطها بأنشطة إشعاعية.
- **معرفي/مناهج:** مواءمة محتوى حسب مادة/مستوى.
- **تنسيق:** تشغيل حدثي/دوري، مخرجات = تنبيه/توصية/مسودة/بطاقة + أدلة + أولوية + حاجة اعتماد.

## 7) أمن وخصوصية وحوكمة (أساس)
- فصل بوابات، مبدأ أقل امتياز ونطاق، مصادقة قوية (تجزئة كلمات مرور، جلسات/تجديد)، HTTPS في الإنتاج.
- تدقيق غير قابل للعبث عمليًا، سياسات احتفاظ/حذف/إخفاء هوية، تقليل بيانات حساسة.
- حوكمة تواصل: موافقة واعتماد قبل إرسال، تسجيل قناة/حالة، احترام الخصوصية.
- حوكمة الذكاء المساند: شفافية (أدلة/مبرر)، قابلية تعديل/رفض بشري، منع استخدام وصمي أو خارج الغرض التربوي.

## 8) أساس الإنتاج (انتقال من النموذج)
- **حالي (Prototype):** Node.js بدون تبعيات خارجية، تخزين `data.json`, واجهة ثابتة مع ربط حي جزئي/موسّع، مفاتيح بيئة أساسية.
- **هدف إنتاجي:** PostgreSQL (أو DB معتمدة) + ترحيل مخطط، واجهة API موثقة، نشر خلف عاكس TLS، نسخ احتياطي ومراقبة، اختبارات وصلاحية بيانات، وإدارة تكوين/أسرار.

## 9) مؤشرات نجاح أساسية
- تحسن إتقان الكفايات المستهدفة وتقليص فجوات حرجة.
- انتظام إعادة التقييم وإغلاق دورة التدخل (بطاقات منجزة/أثر).
- مشاركة أسرية وأنشطة إشعاعية ذات أثر موثق.
- زمن استجابة للتنبيه وجودة قرارات مبنية على أدلة.
- امتثال للخصوصية والتدقيق ورضا المستفيدين.
