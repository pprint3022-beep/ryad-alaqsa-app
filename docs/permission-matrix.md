# مصفوفة الصلاحيات التفصيلية (Permission Matrix)
**المشروع:** Ryad Al Aqsa App — Institut Ryad Al Aqsa / رياض الأقصى  
**المبدأ:** فصل صارم بين **منصة المدير والإدارة (الخادم الرئيسي)** و**الحسابات الخاصة** (معلم/ولي/تلميذ). بعد الولوج لحساب خاص لا تظهر منصة الإدارة إطلاقًا.

## الرموز
- **R** عرض (Read)
- **C** إنشاء (Create)
- **U** تعديل (Update)
- **A** اعتماد/موافقة (Approve)
- **E** تصدير (Export)
- **D** حذف/أرشفة (Delete/Archive)
- **—** لا صلاحية
- **(م)** مقيد بالنطاق (فصوله/أبنائه/مستواه)
- **(ف)** بصلاحية مفوضة

## 3) قواعد الربط والفصل (Enforcement)
- **فصل البوابات:** مسار دخول مستقل لمنصة الإدارة (خادم رئيسي) ومسار للحسابات الخاصة. رمز الجلسة/الدور يحدد البوابة ولا يسمح بالتنقل المتقاطع.
- **RBAC + Scope:** كل صلاحية مرتبطة بدور ونطاق (مؤسسة/مستوى/فصل/مادة/أبناء).
- **تفويض نائب المدير:** صلاحيات (ف) تُعرّف وتُحدّث من المدير وتُسجّل في سجل التدقيق.
- **الخصوصية:** أولياء الأمور والتلاميذ يرون بياناتهم/أبناءهم فقط؛ المعلم ضمن فصوله المسندة.
- **التدقيق:** تسجيل عمليات الإنشاء/التعديل/الاعتماد/التصدير/الحذف في الأقسام الحساسة.
