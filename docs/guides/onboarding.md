# دليل الإطلاق التدريجي — منصة رياض الأقصى

**الهدف والفريق:** إدخال المنصة في أربعة أسابيع بأقل مخاطر، بقيادة الإدارة والمنسّق الرقمي وقادة المواد والدعم التقني.
**مبدأ الإطلاق:** بيانات صحيحة ← معلمون مدرَّبون ← أولياء مطمئنون ← تلاميذ ومجتمع.

## 1) المتطلبات قبل الأسبوع الأول
- Node.js 20 أو أحدث، وتشغيل النموذج من `backend`: `node server.js` ثم فتح `http://localhost:3001`.
- التحقق من الجاهزية: `node tests/prototype-smoke.js` (41 فحصًا).
- نسخة احتياطية من `backend/data.json` قبل أي تعديل.
- قائمة المستخدمين والأدوار والنطاقات (أبناء ولي الأمر، فصول المعلم).
- قناة دعم رسمية ومسؤول رد خلال ساعات العمل.
- إشعار خصوصية مختصر للعائلات، ونموذج موافقة للنشر والأنشطة.

## 2) خطة الأسابيع الأربعة
| الأسبوع | الجمهور | التركيز | المخرجات |
|---|---|---|---|
| 1 | الإدارة والبيانات | الحسابات، الهيكل، الصلاحيات، النسخ الاحتياطي | بيئة مستقرة وبيانات مطابقة |
| 2 | المعلمون | الحضور، الواجبات، التقييم، البطاقات، التواصل | كل معلم ينفّذ دورة كاملة |
| 3 | أولياء الأمور | الولوج، التقارير، الرؤى، الموافقات | تفعيل الأغلبية واطلاع موثّق |
| 4 | التلاميذ والمعرض | المسار، المواد، التقدم، الأنشطة، عرض الإنجازات | تشغيل فعلي وختام مجتمعي |

### الأسبوع 1 — الإدارة والبيانات
- إنشاء الحسابات وتوزيع الأدوار: مدير، نائب، مشرف، كاتب، إدارة عامة.
- التحقق من المستويات (تمهيدي إلى السادس) والفصول والمواد والمناهج المنشورة.
- ربط كل ولي بأبنائه، وكل معلم بفصوله ومواده؛ اختبار الوصول بكل دور.
- تجربة سيناريو ممنوع: ولي يحاول فتح تلميذ آخر، ومعلم يحاول فتح فصل غير مسند.
- تفعيل النسخ الاحتياطي اليومي واختبار الاستعادة، واختيار فصلين تجريبيين ومسؤول بيانات لكل مستوى.

### الأسبوع 2 — المعلمون
- جلسة تدريب عملية على بيانات تجريبية تشمل: فصولي، الحضور، الواجبات والتقييم، تقارير المتابعة، بطاقات التغذية الراجعة، الحالات، التواصل.
- قاعدة ذهبية: كل بطاقة تغذية راجعة تمر بدورة مقترحة ← معتمدة ← قيد التنفيذ ← منجزة.
- تكليف كل معلم بإدخال حضور يوم واحد، وواجب واحد، وبطاقة واحدة قبل نهاية الأسبوع.
- مراجعة أسبوعية للأخطاء المتكررة وتحديث إرشادات قصيرة.

### الأسبوع 3 — أولياء الأمور
- جلسة قصيرة (60 دقيقة) أو فيديو موجه: اختيار «الحسابات الخاصة»، ثم ملخص الأبناء، ثم التقرير.
- شرح الفرق بين التقرير والرؤية التربوية والتصنيف، وأن التوصيات استشارية.
- تدريب على قراءة الحضور والدرجات، وعلى استخدام الرسائل والتعميمات.
- توضيح مسار الموافقات (من يطلب، وماذا يُنشر، وكيف يُسجَّل القرار)، وتخصيص ساعة استقبال أسبوعية ومتابعة غير المفعّلين.

### الأسبوع 4 — التلاميذ والمعرض
- جلسة صفية (30–45 دقيقة): مساري اليوم، المواد، الواجبات، إنجازاتي، مساري وتوصياتي.
- تدريب على قراءة الكفايات ونسب الإتقان، وعلى معنى اقتراحات الذكاء الاصطناعي.
- تفعيل النوادي والأنشطة (التسجيل عبر المعلم/الإدارة)، واختيار عمل واحد لكل فصل للمعرض ومراجعته واعتماده.
- يوم ختامي: عرض الإنجازات، جمع الملاحظات، وتحديد تحسينات الشهر التالي.

## 6) العقبات الشائعة
| العَرَض | السبب المرجّح | المعالجة |
|---|---|---|
| «الخادم غير متاح» | الخادم متوقف أو المنفذ مختلف | شغّل `node server.js` وتحقّق من `http://localhost:3001` |
| «تعذر تسجيل الدخول» | بوابة خاطئة أو بيانات خاطئة | الحسابات الخاصة للأولياء والتلاميذ، والإدارة للموظفين |
| لا يظهر الابن | ربط النطاق غير مكتمل | راجع `scope.children` وربط الملفات |
| بيانات فارغة | جلسة غير مصادقة أو بيانات ناقصة | سجّل الدخول وتحقّق من `data.json` |
| رسالة محجوبة | اعتماد ناقص أو موافقة معلّقة | أكمل الاعتماد وسوِّ الموافقة |
| ظهور تلميذ خارج النطاق | صلاحية موسّعة خطأ | صحّح الدور/النطاق فورًا وسجّل الحادث |
| استيراد مكرر | ملف CSV مكرر أو بلا مفاتيح | نظّف الملف واستخدم معرّفًا فريدًا |
| واجهة قديمة أو بطء | ذاكرة مؤقتة، Service Worker، أو جهاز ضعيف | حدّث الصفحة وامسح التخزين واختبر جهازًا آخر |

## 7) قائمة القرار (Go / No-Go)
**تقني**
- [ ] الخادم يعمل بثبات وفحص الدخان ناجح.
- [ ] النسخ الاحتياطي والاستعادة مجرّبان.
- [ ] الاتصال آمن (HTTPS في التشغيل الفعلي) والجلسات تعمل.

**بيانات وصلاحيات**
- [ ] الحسابات والأدوار والنطاقات مطابقة.
- [ ] عزل البوابات والنطاقات مختبَر بسيناريوهات سلبية.
- [ ] سجل التدقيق يعمل، وسياسة الاحتفاظ معتمدة.

**تدريب وتبنٍّ**
- [ ] 90% من المعلمين درّبوا ونفّذوا دورة كاملة.
- [ ] 80% من الأولياء فعّلوا حسابهم.
- [ ] دليل مختصر وقناة دعم متاحان للجميع.

**حوكمة ومجتمع**
- [ ] الموافقات والنشر والأنشطة موثقة.
- [ ] أعمال المعرض مراجعة ومعتمدة.
- [ ] خطة الشهر التالي وجمع الملاحظات جاهزة.

**القرار:** يُطلق عند استيفاء البنود الحرجة (التقنية والخصوصية والبيانات)؛ وإلا يُؤجل أسبوعًا مع خطة معالجة. لا يُطلق مع تجاوز صلاحيات غير معالج أو موافقات ناقصة.
