# أدلة الاستخدام — منصة رياض الأقصى

فهرس الأدلة العملية لكل دور في منصة **رياض الأقصى / Institut Ryad Al Aqsa**. تصف الأدلة الواجهة الحالية والبيانات التجريبية، وتلتزم جميعها بقواعد الخصوصية والمراجعة البشرية وفصل البوابات.

## الأدلة

| الدليل | الجمهور | وصف مختصر |
|---|---|---|
| [بوابة الإدارة](admin.md) | المدير، النائب، المشرف، الكاتب، الإدارة | الروتين اليومي، الاعتمادات، التقارير، سجل التدقيق، وسياسات الخصوصية. |
| [بوابة المعلم/ة](teacher.md) | المعلم/ة المسند/ة إلى فصول ومواد | الحضور، الواجبات والتقييم، بطاقات التغذية الراجعة، الحالات، والتواصل الأسري. |
| [دليل ولي الأمر](parent.md) | أولياء أمور التلاميذ | ولوج الحساب الخاص، متابعة الأبناء، التقارير والرؤى، والموافقات. |
| [دليل التلميذ](student.md) | التلاميذ | مساري اليوم، المواد، الواجبات، الإنجازات، وفهم التوصيات. |
| [الإطلاق التدريجي](onboarding.md) | الإدارة والمنسّق الرقمي والدعم | خطة أربعة أسابيع، جلسات التدريب، فحوص النجاح، وقائمة Go / No-Go. |

## ملاحظات مشتركة

- البوابتان منفصلتان: **بوابة الإدارة** للموظفين، و**الحسابات الخاصة** للمعلم والولي والتلميذ.
- حسابات التدريب: `director@ryad.ma` · `teacher@ryad.ma` · `parent@ryad.ma` · `student@ryad.ma` — كلمة المرور `1234`.
- مخرجات الذكاء الاصطناعي والوكلاء استشارية، وتخضع دائمًا لمراجعة بشرية وموافقة موثقة.
- حالة الوثائق والاختبارات العامة: راجع [`docs/status.md`](../status.md).
